How it works

STEP 1

Install and run

PoEmotes finds your Client.txt automatically for Steam and standalone installs of PoE 1 and 2, then sits in your tray.

STEP 2

Line it up

Press Ctrl+Shift+L, drag the overlay over PoE's chat box, resize it, then press it again to lock. It becomes click-through.

STEP 3

Chat like normal

Type in PoE exactly as you always do. Emote words turn into emotes on the overlay. Hover it to get PoE's chat and item links back.

It never touches the game

PoE writes every chat message to logs/Client.txt. PoEmotes only reads that file, the same way trade-whisper helpers do. No memory reading, no packet sniffing, no injected input, no modified game files. Your keyboard and mouse go straight to PoE.

FAQ

Do my friends need PoEmotes to see my emotes?

Yes. Without it they see the word, like KEKW. Anyone running PoEmotes sees the image.

Can I still click item links?

Yes. Rest the mouse on the overlay for a moment and it disappears, leaving PoE's own chat with its item links. Move away and it comes back. The overlay can't show item tooltips itself, because item details aren't in Client.txt.

The overlay doesn't show over the game

Set PoE to Windowed Fullscreen or Windowed in Options → Graphics. Exclusive fullscreen draws over every overlay.

Where are my settings?

Right-click the tray icon and choose Settings. They're saved in %APPDATA%\PoEmotes.

Windows SmartScreen warns me when I run it

The app isn't code-signed yet, so Windows doesn't recognise it. Click "More info" and then "Run anyway". The source is on GitHub if you'd rather build it yourself.

Does it work on PoE 2?

Yes. It auto-detects whichever game wrote to its log most recently, or you can set the Client.txt path in settings.
